使用指南

① 一次性准备：让电脑能连上 Gitea

  1. 本机需要安装 Git（本工具的所有操作都通过它完成）。
  2. 确认你有 SSH 密钥：检查 C:\Users\你的用户名\.ssh\id_rsa.pub 是否存在。没有就在终端运行 ssh-keygen -t rsa -b 3072 一路回车生成。
  3. 打开 id_rsa.pub，复制全部内容，到 Gitea 网页端「设置 → SSH / GPG 密钥」里添加。
  4. 验证：终端运行 ssh -T -p 2222 git@10.0.0.2，看到 Hi there, 你的用户名! 即配置成功。

② 把仓库加进来

左上角「+ 添加」提供四种方式，路径都可以点「浏览…」直接选文件夹：

  • 克隆：地址填 ssh://git@10.0.0.2:2222/用户名/仓库名.git（在 Gitea 仓库页面可复制）；
  • 扫描目录：选一个代码总目录，自动找出里面所有 git 仓库；
  • 打开：单独添加一个已有仓库；
  • 新建：从零创建本地仓库（自动完成首次提交）。

③ 日常工作流

  1. 改代码后，「更改」页勾选要提交的文件（勾选 = git add）；
  2. 填写提交说明，点「提交到 分支名」；
  3. 点顶栏「推送」同步到 Gitea。开始工作前建议先「拉取」。

④ 常见问题

  • 推送失败 / 认证失败：先按第 ① 步验证 SSH；确认仓库远程地址是 SSH 形式。
  • 提交人不对：点顶栏 ⚙ 检查全局和仓库级身份。
  • 想临时收起改动：用「贮藏」，之后在「贮藏」页恢复。
  • 提交错了：只要还没推送，「更改」页会出现「撤销最近一次提交」。
